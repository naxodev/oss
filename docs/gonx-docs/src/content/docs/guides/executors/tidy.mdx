The tidy executor runs `go mod tidy` to ensure the go.mod file matches the project source code.

## Usage

```bash
nx tidy my-go-project
```

## Inferred target

Inferred for all Go projects (applications and libraries):

```json
{
  "executor": "@naxodev/gonx:tidy",
  "cache": true,
  "inputs": [
    "{projectRoot}/go.mod",
    "{projectRoot}/go.sum",
    "{projectRoot}/**/*.{go}"
  ]
}
```
